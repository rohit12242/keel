The palette: paper #F2F1EC, ink #1C1D19, rules #DAD9D1, effort green #3F6650, structure blue #3C5880, deviation red #8A473E. Type: Spectral for headings, Archivo for interface text, IBM Plex Mono for every figure. Keep figures tabular-nums so columns line up.
Review has left the sidebar — a review is something you do to an objective, not a place you visit. Effort has left the objective overview and has its own tab. Nothing in the parking lot is ever deleted.
keel-app-screens.html in this folder is the same fifteen screens on one pan-and-zoom canvas, with the design notes attached. The .dc source files are in canvas-source/ if the canvas ever needs rebuilding.
